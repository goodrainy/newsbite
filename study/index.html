API (Application Programming Interface)
운영체제나 프로그래밍 언어가 제공하는 기능을 응용 프로그램에서 쓸 수 있게 만든 인터페이스. 응용프로그램에서 데이터를 읽거나 쓰기 위해 사용함. 필요한 정보를 얻으려면 API에 요청하고 응답을 받아 사용해야 함.
구분설명

Public API / Open API누구나 쓸 수 있게 공개된 API
