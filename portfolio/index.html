뉴스한입 — 포트폴리오

매일 쏟아지는 뉴스를 짧게 정리해서 보여주고, 모르는 용어와 관련 주가까지 한 번에 확인할 수 있게 만드는 걸 하고 있습니다.

실제 동작 기능 4개 버그 수정 7회 연동 외부 API 3개

① 문제

시간은 없는데 뉴스는 제대로 공부해보고 싶었던 게 진짜 문제였습니다. 기사는 너무 많고, 모르는 용어는 낯설고, 사회 이슈와 주가의 연관성은 감으로만 알았습니다. 이 불편을 겪은 건 본인 스스로였고, 그래서 뉴스 요약·용어사전·주식 예측 세 축으로 서비스를 좁혔습니다.

② 내가 한 것

실제로 동작하는 기능은 뉴스 요약, 사회 뉴스로 보는 주식, 용어사전, 데이터 백업 4가지입니다. 뉴스 요약은 카테고리별로 오늘 또는 지난 7일 기사를 중복·무관 기사를 걸러 보여줍니다. 사회 뉴스로 보는 주식은 관련 기사를 보고 오를지 내릴지 예측한 뒤, 나중에 실제 종가와 비교해 적중 여부를 보여줍니다. 용어사전은 기본 용어와 우리말샘 조회, 직접 작성을 함께 지원하고 어느 기사에서 만난 용어인지 문맥까지 기록합니다.

③ 결과

배포 주소는 https://my-newsbite.vercel.app/ 입니다. 중복 기사 판별 로직은 실제 기사 24개(같은 사건 18쌍·다른 사건 258쌍)로 검증해 기준값 0.12에서 놓친 쌍과 잘못 합친 쌍 모두 0개를 확인했습니다. 인기 종목은 최근 기사 1000건(API 최대치)을 받아도 하루를 못 거슬러 올라간다는 것도 실측으로 확인했습니다.

④ 자른 기능과 이유

기사 본문 전체를 요약하는 기능은 네이버 API가 본문 자체를 제공하지 않아 멈췄고, 제목과 키워드 기반 요약으로 대체했습니다. 종목 뉴스를 종가 기준일과 정확히 같은 날짜로 맞추려던 계획도, 인기 종목은 API 한도 안에서 그 날짜에 도달조차 못 한다는 걸 확인하고 접었습니다 — 대신 오늘 기사로 예측하는 방식으로 바꿨습니다. 디자인 스킬이 제안한 아이콘·일러스트도 적용해봤지만 원래 버전보다 못하다고 판단해 되돌렸습니다.

⑤ AI를 어떻게 썼나

코드 작성과 배포, 버그 진단까지 전 과정을 AI와 함께 했습니다. 코드를 여러 조각으로 나눠 전달하는 과정에서 코드 블록이 통째로 빠지는 실수가 두 번 있었고, 배포된 사이트를 다시 불러와 원본과 비교하는 방식으로 매번 찾아 고쳤습니다. 동음이의어 처리, 검색 출처 기록, 스크립트 이스케이프 같은 버그도 같은 방식으로 총 7번 수정했습니다.

⑥ 다음에 할 것

로그인을 붙여 여러 기기에서 기록을 이어볼 수 있는 앱으로 만들고 싶습니다. 경제 전문 매체의 API를 유료로 받아 경제·경영 특화 서비스로 발전시키는 것도 고려 중입니다. 지금 쓰는 중복·무관 기사 판별 기준은 기사 24개로 검증한 값이라, 더 다양한 기사로 다시 검증해볼 필요가 있습니다.
